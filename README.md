# Unity-PlaneGame
Simple flying game for a school assignment. The objective is to fly through all 10 gate points. Pass through all of them and you win, make sure not to hit the mountains! The game needs more polishing, it is playable, but not as great as I want it to be yet.

## How to build the game yourself?
Since its a Unity game you need to [install](https://cloud.unity.com/home/organizations/5773926382149/onboarding/post-download) Unity to your computer <br>
<br>
Clone the repository
```
git clone https://github.com/martinprs/Unity-PlaneGame.git
```
Open the project in Unity and go to **File** -> **Build settings** (select all scenes) -> **Build**
